# Prompt 1: Análisis inicial del formulario

Analiza el archivo Hoja de Registro de Tripulación de mi landing page. 
Identifica problemas de seguridad, rendimiento, lógica y calidad de código. 
Clasifica cada hallazgo según: desactualizado, incompatibilidad, seguridad, 
rendimiento o lógica. Indica nivel de severidad (crítico/moderado/menor) 
y explica el impacto si se despliega sin corrección.

# Prompt 2: Verificación de vulnerabilidades XSS

Revisa el manejo de inputs del formulario. Identifica posibles vulnerabilidades 
de XSS, inyección de código o falta de sanitización. Sugiere correcciones 
específicas con código.

# Prompt 3: Optimización de validación

Analiza la lógica de validación del formulario. Verifica si usa APIs modernas, 
si el manejo de errores es robusto, y si hay código redundante o ineficiente. 
Proporciona versión corregida.

# Prompt 4: Accesibilidad y mejores prácticas

Evalúa el formulario según estándares de accesibilidad (ARIA labels, 
navegación por teclado, mensajes de error claros) y mejores prácticas 
de desarrollo web moderno.
